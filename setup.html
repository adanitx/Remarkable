Remarkable: permisos necesarios

Remarkable necesita estos permisos para mostrar el buscador en tus páginas. Puedes concederlos ahora mismo.

1. Acceso a los sitios web

Permite mostrar el buscador y el halo en cualquier página web.

Estado: comprobando…

2. Acceso a archivos locales (PDF abiertos desde el disco)

Permite usar Remarkable en archivos file://. Chrome no permite concederlo desde una extensión: hay que activarlo a mano.

Estado: comprobando…

En la página que se abrirá, activa «Permitir acceso a las URL de archivos». Después vuelve aquí y pulsa «Actualizar estado».

Si cambias un permiso con pestañas ya abiertas, recarga esas pestañas para que el buscador se active en ellas.
